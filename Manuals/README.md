# CFAST Manuals

All of the CFAST manuals are contained within the sub-folders above. Each sub-folder contains a bash script called `make_guide.sh` that will run PDF-LaTeX and BibTeX enough times to completely compile the guide and update the references. Sub-sub-folders contain both `FIGURES` and `SCRIPT_FIGURES`, the latter being figures that are generated by scripts and not committed to the repository.

For searchable HTML editions generated from these same LaTeX sources, see [CFAST online manuals](Online_Docs/README.md).

Copy generated figures and tables from another CFAST checkout with `Copy_Firebot_Figures.sh`. The script copies each available `SCRIPT_FIGURES` directory recursively into the manuals beside the script, replacing matching files and keeping other local files. The default source repository is `/home/firebot/FireModels_cbot/cfast`; override it with `--repo-root`:

```sh
./Copy_Firebot_Figures.sh --repo-root ~/spark_home/firebot/FireModels_cbot/cfast
```
